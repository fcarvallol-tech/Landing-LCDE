# Fotos de productos

Deja acá las fotos de los productos. La página las toma automáticamente desde esta carpeta.

## Nombres de archivo exactos

| Archivo | Producto |
|---|---|
| `tradicional.jpg` | Pack Tradicional |
| `cm.jpg` | Pack CM (juego + bolso) |
| `im.jpg` | Pack IM (juego + reloj) |
| `gm.jpg` | Pack GM (juego + reloj + bolso profesional) |
| `reloj.jpg` | Reloj de ajedrez en su cajita |

Opcionales, si tienes más de una foto por producto (se muestran como galería):

`tradicional-2.jpg`, `tradicional-3.jpg`, `cm-2.jpg`, `cm-3.jpg`, y así con cada uno.

Otras imágenes:

| Archivo | Uso |
|---|---|
| `../hero.jpg` | Foto grande del inicio de la página (idealmente horizontal, 1600×1000 o más) |
| `../logo.png` | Escudo de la marca, fondo transparente |
| `../og.jpg` | Imagen que se ve al compartir el link (1200×630) |

## Recomendaciones

- **Formato**: `.jpg` para fotos, `.png` solo si necesitas fondo transparente.
- **Tamaño**: al menos 1200px de ancho. La página las optimiza sola, así que sube la mejor
  calidad que tengas.
- **Fondo**: parejo y claro (una pared blanca, un mantel beige). Todas las fotos con el mismo
  fondo se ven diez veces más profesionales que fotos buenas con fondos distintos.
- **Luz**: de día, junto a una ventana, sin flash.
- **Encuadre**: cuadrado (1:1) para las fotos de producto. Deja aire alrededor.
- **Muestra el contenido completo del pack**: si el pack incluye bolso, el bolso tiene que
  aparecer en la foto principal.

## Mientras no haya fotos

La página funciona igual: muestra un placeholder ilustrado con la paleta de la marca. Apenas
subas un archivo con el nombre correcto, se reemplaza solo.
